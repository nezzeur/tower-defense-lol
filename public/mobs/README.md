# Custom enemy images

Drop PNG files here (transparent background works best) named after the enemy id.
The battle draws them instead of the built-in pixel sprites; any missing file
falls back to the built-in sprite. Images are scaled to the enemy's size and
mirrored when walking left, so draw them facing right.
